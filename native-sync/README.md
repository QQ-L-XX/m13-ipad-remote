# Optional player patch source

仅供理解已验证的 2.22 控制接口。构建面板不需要执行这些文件。不要在未知版本 APK 上直接运行补丁。

Source reference for the verified custom 2.22 control integration. Not required for building the standalone panel. Do not apply it to unknown APK versions.

See [player integration](../docs/player-integration.md). `PatchHomeDex.java` requires external dexlib2 dependencies and a separately supplied, authorized exact base APK; neither those libraries nor the full player binary/private key is bundled here.
